Project

Kalkulator Geometri Berbasis C++

Program konsol sederhana berbasis menu untuk menghitung bangun ruang dan segitiga. Pengguna memilih menu lalu memasukkan sendiri nilai yang dibutuhkan, dan program menampilkan hasil perhitungannya.

  • Menghitung luas permukaan beberapa bangun ruang dengan function overloading, sehingga satu nama fungsi dipakai untuk bangun ruang yang berbeda.
  • Mencari panjang sisi miring (hipotenusa) segitiga dari sisi-sisi yang dimasukkan.
  • Menghitung nilai sin, cos, dan tan pada ketiga sudut segitiga.
  • Menyediakan menu interaktif agar program mudah digunakan.

Yang dipelajari: penggunaan fungsi dan function overloading, perhitungan trigonometri dalam kode, serta menyusun program agar interaktif dan rapi.
